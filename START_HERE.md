## Development Loop
1. Confirm the plan and next task.
2. Implement the smallest effective change.
3. Verify behavior.
4. Update docs and runtime state.
5. Leave a clear handover before stopping.

## Objective
Progress the repository while keeping it legible, safe, and easy to resume.
