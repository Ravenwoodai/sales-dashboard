# Refactor Prompt
Refactor code to improve clarity, modularity, and maintainability without changing intended behavior.

## Required Process
1. Read `AI_SYSTEM.md`, `docs/ARCHITECTURE.md`, `docs/SYSTEM_MAP.md`, and `agent/INSTRUCTIONS.md`.
2. Define the exact refactor scope and modules involved.
3. Preserve behavior; do not mix feature work into refactors.
4. Apply small, reviewable changes with clear module boundaries.
5. Verify output parity with existing behavior.
6. Update documentation when structure or responsibilities change.

## Constraints
- Prefer simplification over abstraction.
- Avoid speculative rewrites.
- Record architectural tradeoffs in `docs/DECISIONS.md` when relevant.
